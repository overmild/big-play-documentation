# Decisions (ADRs)

Architecture/Decision Records — short docs that capture a significant decision **and the reasoning behind it**, written at the time it's made so nobody has to reverse-engineer "why did we do it this way?" six months later.

## When to write one
- Any decision that would be costly or awkward to reverse
- Any decision where reasonable people disagreed and a call had to be made
- Naming/structural conventions that future contributors need to follow

Small, easily reversible choices don't need an ADR.

## Numbering
Sequential: `0001-title.md`, `0002-title.md`, etc. Never reuse or renumber — if a decision is later reversed, write a *new* ADR that supersedes it and note that in both files.
