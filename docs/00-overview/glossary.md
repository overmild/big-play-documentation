# Glossary

Plain-language definitions of any term used across these docs that isn't obvious to a non-technical reader. Add to this as you write other docs — if you had to explain a term out loud, it belongs here.

| Term | Definition |
| --- | --- |
| ADR | "Architecture/Decision Record" — a short doc that captures a decision and the reasoning behind it, so people later understand *why*, not just *what*. |
| RFC / Proposal | A write-up of an idea before it's built, so people can weigh in while it's still cheap to change. |
| Requirement | A specific, testable statement of something the product must do. |
