# Requirements

This folder holds concrete statements of what Big Play needs to do. Each requirement is its own file so it can be discussed, revised, and linked to independently.

## When to write one
Once an idea in `docs/02-ideation` has been discussed and accepted, turn the agreed-upon parts into one or more requirement docs here.

## Status values
- **Draft** — being written, not yet reviewed
- **Proposed** — ready for feedback
- **Approved** — agreed, ready to be built against
- **Implemented** — built
- **Deprecated** — no longer applies (keep the file, don't delete — note why in the file)
